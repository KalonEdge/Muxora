# Security

If you believe you've found a security issue in Muxora, please report it privately rather than in public, through [kalonedge.com/contact](https://kalonedge.com/contact).

Please include the version of Muxora (Muxora › About Muxora), your version of macOS, and the steps that show the issue.

## Supported versions

Security fixes go into the latest release. Muxora installs updates by itself, so keeping automatic updates on (Settings › Updates) keeps you protected.
